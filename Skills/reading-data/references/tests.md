# Reading data test selection

Choose storage **or** import/generation coverage first; do not run both by default.
Kotlin classes are in `com.ssmath.app`, under `${TEST}/<Class>.kt`.
Python tests are in `${DATA}/test_generation.py`.
[Shared validation](../../repo-router/references/validation.md) owns exact runner
commands, environment versions, and Python standard-library workflows. Use its
targeted selectors together in one invocation; no extra test tools/dependencies.

## Storage, revisions, and allocations

Start with the matching `ReadingSqliteStoreTest` methods:

| Behavior | Existing method(s) |
| --- | --- |
| Empty install | `freshInstallIsEmptyAndEmptySelectionDoesNotConsumeAnything` |
| Rotation/resume | `randomCyclesExhaustPoolAndAvoidImmediateBoundaryRepeats`, `reopenAndResumeKeepCycleAndAssignmentsIncludingSkippedActivities` |
| Transactional reservations | `failedLedgerWriteRollsBackActivityReservationAndStaleStartsAreRejected`, `sessionBatchReservationsAndLedgerRollbackTogetherOnFailedWrite` |
| Assigned content revisions | `everyAssignedSessionRevisionSurvivesReimportReopenAndResume`, `reimportAndAdditionsPreserveCycleAndPriorContentRevisions` |
| Read-only saved review | `reviewAfterRestartUsesAssignedRevisionAndKeepsTheCurrentDraftAndRotation` |
| Deletion receipts | `deletedSessionsStayDeletedAfterRestartWithoutResettingInstalledContentOrRotation` |
| Migration | `legacyMigrationPreservesDraftsHistoryAndCreditWithoutInstallingAPack`, `upgradesPurgeRetiredCataloguesAndHistoryWhileKeepingOtherRevisionsAndRotation` |
| Corrupt legacy file | `brokenLegacyFileNeverCreatesAnEmptyReplacementLedger` |
| Bounded payload/history | `largeLibraryKeepsOnlyActivePayloadInTheLoadedReadingState`, `largeHistoryUsesBoundedRowsAndMigratesOversizedVersionOneLedgers` |

For legacy JSON/`ReadingMigration`, use the storage subset of `ReadingStoreTest`:
`corruptUnreadableOrUnsupportedFilesAreNotSilentlyReplaced`,
`atomicBackupRecoversTheLastCommittedSnapshot`,
`retiredGamesArePurgedBeforeLegacyDecodingWithoutChangingOtherReadersOrStories`,
and `retiringOtherGamesKeepsTheCurrentDraftAndRejectsUnrelatedCorruption`.
Its actor/timer tests belong to [reading runtime selection](../../reading/references/tests.md).

For browsing, use `ReadingCatalogBrowserTest` for bounded queries, pool filters,
revision selection, and independent connections; start with
`filtersCombineGameAndLevelAndDetailUsesTheRevisionSelectedInThePage`.
Use `ReadingDatabaseBrowserTest` only for browser UI, especially
`emptyInstalledDatabaseDoesNotFallBackToBundledContent`,
`failedPageCanBeRetriedAndMissingDetailsCanBeExited`, or
`pagesInstalledActivitiesFiltersThemAndReturnsFromDetailWithoutChangingTheCatalog`.

## Schema, download, and import

Start with the changed boundary in `ReadingPackTest`:

- URL/manifest policy: `onlyExactCredentialFreeHttpsRepositoryPathsAreAllowed`,
  `manifestsRejectUnsupportedVersionsPathsAndUnboundedCountsBeforeDownloading`.
- Schema: `everyGameRejectsItsInvalidSchemaAndAnswers`,
  `malformedJsonUnknownGamesAndUnexpectedFieldsRollBackAnExistingCatalogue`,
  `duplicateActivityIdsAreRejectedBeforeInstallingAnyRows`.
- Limits/integrity: `oversizedManifestAndRecordInputsAreBoundedAndInvalidUtf8IsRejected`,
  `checksumCountAndByteFailuresNeverReplaceTheInstalledPack`.
- Cancellation: `aFailedStreamOrCancellationLeavesThePreviousPackAndCleansItsDownload`,
  `cancellationAfterStagingRowsRollsBackTheTransaction`.
- Compatibility/revisions: `idsCannotMoveGameOrLevelEvenWhenOnlyAnArchivedRevisionExists`,
  `updatesAreAdditiveAndKeepOldRevisionsAcrossReopeningTheDatabase`,
  `serializationFormattingDoesNotCreateNewContentRevisions`.

Import controls use `ReadingPackSettingsTest`, particularly
`failedImportKeepsInstalledLibraryAndReaderProgress` and
`readingSettingsKeepsImportControlsSeparateFromAdminBrowser`.
For home import gating only, add `ReadingEntryTest` and
[app-shell guidance](../../app-shell/SKILL.md), rather than loading runtime rules.

## Generator selection

Use these exact classes in `${DATA}/test_generation.py`:

- `WordSentenceStructureTest`: current word tiles, bounds, alternatives, repeated
  words, and contextual answers. Useful methods:
  `test_every_tile_is_one_word_with_punctuation_and_a_distinct_position`,
  `test_curated_adverb_alternatives_preserve_words_punctuation_and_bonus_evidence`.
- `GrammarLessonTest`: objectives, progression, examples, and stable variant IDs;
  `test_each_concept_has_twenty_distinct_contexts_and_stable_variant_ids`.
- `LegacySentenceStructureTest`: legacy phrase frames/missing-word compatibility,
  not the current word-Scramble generator.
- `PublishedPackTest`: generated bytes, manifests, compatibility aliases/counts;
  `test_published_files_reproduce_exactly`,
  `test_v7_compatibility_entry_points_and_immutable_pack_are_preserved`,
  `test_v8_entry_point_stays_byte_identical_and_safe_for_legacy_index_only_scoring`,
  `test_all_scrambles_change_with_stable_ids_and_every_other_v9_line_is_unchanged`.

## Escalate only for the changed contract

`ReadingSummitTest` covers real-pack Summit upgrades/reopen behavior.
`ReadingBulkPackTest` is the broader published-pack escalation, after focused
tests: use `wordScramblesMeetEveryLevelRangeAndAllPublishedSentencesCanBeCompleted`
or `wordScrambleUpdateKeepsLegacySessionRevisionsAndUsesNewWordsForNewGames`
when validating current Scramble data end-to-end.
For deletion/rewards contracts, add `ReadingRewardsTest`'s
`durableDeletionReceiptsFinishRewardCleanupAfterFailureAndRestart` and consult
[rewards](../../rewards/SKILL.md). No checkpoint-to-points conversion is expected.
